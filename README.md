# AutoTakeoff AI — Motor Universal de Cómputos Métricos

Plataforma inteligente para la extracción automatizada de metrajes y generación de presupuestos de obra civil a partir de planos arquitectónicos (PDF / Imagen) impulsada por IA Multimodal.

Desarrollado por **CarMiDev**.

## Características
- Extracción automática de recintos, cotas y vanos de puertas (P 0.86x2.10m).
- Deducción precisa de vanos en paredes y rodapiés.
- Criterios dinámicos de obra (factor de desperdicio, merma directa o por rendimiento, altura libre).
- Tabulador de partidas con precios unitarios en USD editable en tiempo real.
- Exportación multi-hoja a Excel (.xlsx) con SheetJS.
- Preparado para migración a Supabase con Row Level Security (RLS).
